# 📈 Stock Trading Platform

A Java-based Stock Trading Platform developed as part of the **CodeAlpha Java Programming Internship**. This project simulates a stock market environment where users can explore stocks, perform buying and selling operations, and manage their investment portfolio.

## 🚀 Features

- 📊 **Stock Market View:** View available stocks and their prices.
- 💰 **Buy Stocks:** Simulate stock purchases.
- 💸 **Sell Stocks:** Simulate selling owned shares.
- 📁 **Portfolio Management:** Keep track of stock holdings.
- 📈 **Investment Tracking:** Monitor portfolio value and investment performance.
- 📝 **Transaction History:** Maintain a record of trading activities.
- 🛡️ **Input Validation:** Handle invalid inputs and trading operations.

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- Exception Handling
- File Handling (if implemented)

## ⚙️ Getting Started

### Prerequisites

- Java Development Kit (JDK) installed
- A code editor or IDE, such as VS Code, IntelliJ IDEA, or Eclipse
- Git installed (optional, for cloning the repository)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/angelverma4296-maker/CodeAlpha_StockTradingPlatform.git
```

**2. Navigate to the project directory**

```bash
cd CodeAlpha_StockTradingPlatform
```

**3. Open the project**

Open the folder in your preferred Java IDE and locate the main Java class containing the `main()` method.

**4. Compile and run**

If your project uses a single Java file, run:

```bash
javac Main.java
java Main
```

Replace `Main.java` with the actual filename if your main class has a different name.

For projects containing packages or multiple source files, compile and run them according to your project structure or IDE configuration.
